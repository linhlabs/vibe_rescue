# v0.8-preview — phạm vi năng lực

[English](V0.8_PREVIEW.md) · Metadata gói: `0.8.0-preview` (công cụ đóng gói có
thể chuẩn hóa thành `0.8.0rc0`). Đây là **bản preview của workflow generic**,
không phải chứng nhận cho mọi repo. Cài từ source checkout như README; chưa hỗ
trợ Python wheel.

## Team khác chạy được gì hôm nay

```bash
python scripts/repo_explorer.py --generic \
  --root /path/to/project --sources src tests \
  --profile agent --profile pii \
  --out /path/to/project/VIBE_RESCUE/source-explorer.html
```

Chỉ chọn thư mục source được phép đọc. Lệnh chạy offline và ghi đồng thời
`architecture.html/.json`, `source-explorer.html/.json`. Trang đầu nối claim
từ tài liệu có giới hạn đọc với khối thư mục, lời gọi/import Python ở mức
source, bước tài liệu ghi tên hàm chính xác trong backtick, *đường dẫn*
config/prompt, control candidates và unknowns. Trang sau cho xem tham số,
caller/callee, guard và raise của Python. Ngôn ngữ khác được đưa vào danh sách
file; lệnh generic này chưa nối hàm của chúng với Python hoặc UI/HTTP. Công cụ
`logic_atlas.py` riêng có bản đồ từng ngôn ngữ cùng giới hạn ghi trong
[LOGIC_ATLAS.md](LOGIC_ATLAS.md).

`rescue_voyage.py --path /path/to/project --stages map,prove,review` chạy được
workflow scanner và agent review khi chính sách source/provider của target cho
phép. Khác Atlas theo scope, MAP đọc từ root của target. Plan, repair và merge
cần quyết định owner; worktree và kiểm diff không cách ly tiến trình
agent/scanner khỏi quyền host. Đọc [SECURITY.md](../SECURITY.md) và
[owner pact](OWNER_PACT.md) trước khi FIX repo thật.

Bản control review sâu do reviewer độc lập
viết sau khi lần theo code path và test tập trung. Vibe Rescue **chưa tự tạo
được mức đánh giá đó** cho mọi team. Test xanh hay hàm tên `mask` không đủ để
kết luận an toàn hoặc production-ready.

## Bằng chứng preview và cổng còn mở

- Trên repo mẫu Python/TypeScript/config độc lập, Atlas generic chạy từ cwd
  khác với `--sources .`: 3 file code, 3 block, 2 quan hệ tĩnh và 2/2 bước
  ghi tên hàm chính xác được nối. ID hàm không có vẫn giữ unknown. Đây là
  bằng chứng portability của EXPLORE, chưa là trace full-stack hay FIX.
- [Hợp đồng Architecture Atlas](ARCHITECTURE_ATLAS.md) ghi mức bằng chứng,
  scope loại trừ và giới hạn parser. [Mục tiêu dài hạn](PRODUCT_NORTH_STAR.md)
  và [PLAN V1.0](../PLAN.md) vẫn còn hiệu lực; `v0.8-preview` chưa đóng cổng
  control hoặc release của chúng.
- Build wheel hiện lỗi vì setuptools không phân biệt được các package ở root.
  Lệnh chạy từ source checkout ở trên vẫn hoạt động; chưa quảng bá
  `pip install vibe-rescue` trước khi thiết kế và test layout cài đặt.
- Trước khi gọi target production-ready, team phải tự xác minh đúng build và
  config đang chạy bằng trace UAT/production, fault injection, security review
  và bộ case theo domain. Artifact nhạy cảm giữ trong workspace của team đó.
